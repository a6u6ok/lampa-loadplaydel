# Плагин для скачки и просмотра qBittorrent в Lampa (Keenetic + Entware + SMB)

Плагин для медиапортала **Lampa**, обеспечивающий прямую интеграцию с торрент-клиентом **qBittorrent**. Позволяет добавлять торренты, отслеживать прогресс, удалять задачи и запускать воспроизведение видеофайлов по локальной сети через протокол **SMB** прямо из интерфейса Lampa.

Скрипт оптимизирован как для стандартных браузерных/ТВ оболочек, так и для нативных Android-приложений (с поддержкой `AndroidJS`).

## 🔥 Ключевые возможности

- **Интеграция в интерфейс:** Добавляет аккуратный блок кнопок управления (`qB` / `Загрузить`, `Плеер` / `Файлы`, `Удалить`) прямо в карточку торрента Lampa.
- **Умный парсинг серий:** Автоматически распознает сезоны и серии в названиях файлов (`S01E02`, `1x02`, `Сезон/Серия`) и сортирует их по порядку для удобного переключения.
- **Гибридный сетевой стек:** Автоматически переключается между стандартным `fetch` и нативным Android-интерфейсом (`AndroidJS`) в зависимости от платформы.
- **Умный роутинг SMB (Samba):** На лету генерирует корректные URL-пути для воспроизведения полностью скачанных видеофайлов, поддерживая режимы создания отдельной подпапки (`Subfolder`) или загрузки в корень (`NoSubfolder`).
- **Автоматическая остановка раздач:** Умеет останавливать раздачи при достижении 100% прогресса (настраивается: останавливать *все* раздачи на сервере или *только добавленные через Lampa*).
- **Безопасность логов:** Автоматически маскирует авторизационные данные (пароли SMB) при выводе отладочной информации.

## 🛠 Инструкция по установке

1. Откройте **Lampa** ➡️ **Настройки** ➡️ **Плагины**.
2. Нажмите **Добавить плагин**.
3. Введите адрес скрипта:
   `https://a6u6ok.github.io/lampa-loadplaydel/preload.js`
4. Нажмите **Сохранить/Добавить** и полностью перезапустите приложение Lampa.

## ⚙️ Настройка параметров

После установки плагин добавит пункт **qBittorrent** в боковое меню Lampa или в раздел настроек компонентов. Вы также можете настроить его через встроенный мастер настройки (Wizard) при первой попытке взаимодействия.

### Обязательные параметры:
- **Адрес сервера qBittorrent:** URL-адрес вашего Web UI (например, `http://192.168.1.1:9080`).
- **Путь загрузок на сервере:** Абсолютный путь, куда qBittorrent сохраняет файлы (например, `/mnt/storage/torrents`).
- **Адрес SMB-папки:** Сетевой путь до этой же папки для плеера (например, `smb://192.168.1.1/Media/`).

## 📐 Архитектурные особенности и стабильность

В коде реализованы важные механизмы отказоустойчивости для специфических ТВ-платформ:
1. **Защита от зависаний в AndroidJS (Лонг-пуллинг):** В среде AndroidJS запросы обрабатываются через циклический опрос (`poll`) с лимитом в `~20 секунд`. По истечении таймаута поток освобождается.
2. **Обработка пустых ответов (`emptySuccessAfter`):** Некоторые сборки Android-приложений Lampa не возвращают тело ответа на команды управления (пауза, удаление). Плагин принудительно завершает опрос через 1.5 секунды и валидирует статус напрямую.
3. **Безопасная деградация (jQuery/Vanilla JS):** Если в текущей сборке Lampa отсутствует jQuery, плагин выведет текстовое предупреждение пользователю вместо фатального сбоя всего приложения.

## 🪵 Отладка (FAQ)

1. Перейдите в настройки плагина и включите параметр **Режим отладки (DEBUG)**.
2. Откройте встроенную консоль логов приложения Lampa.
3. Все события плагина логируются с префиксом `[qBittorrent]`. Пароли SMB скрываются маской `smb://***@...`.

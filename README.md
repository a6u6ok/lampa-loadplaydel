# qBittorrent Direct Plugin for Lampa (Keenetic + Entware + SMB)

Это модифицированный плагин для **Lampa**, который позволяет интегрировать ваш домашний торрент-клиент **qBittorrent** (запущенный, например, на роутере Keenetic через Entware) и запускать полностью скачанные видеофайлы напрямую через Lampa.

Этот плагин сохраняет все настройки внутри хранилища Lampa (`Lampa.Storage`).

## 🚀 Возможности

- **Интеграция с qBittorrent:** Добавление торрентов по magnet-ссылкам прямо из карточки фильма в Lampa.
- **Индикация загрузки:** Прямо в интерфейсе Lampa отображается текущий процент скачивания торрента.
- **Прямое воспроизведение по SMB:** Автоматический расчет пути и запуск видеофайла в локальном плеере на Android/ТВ по протоколу `smb://`.
- **Управление торрентами:** Кнопка быстрого удаления задачи из qBittorrent прямо из интерфейса.
- **Мастер первой настройки:** При первом запуске плагин сам предложит заполнить ключевые поля, а пустые параметры в настройках Lampa будут аккуратно подсвечены как «Пусто».
- **Защита от падений:** Реализован глобальный перехват ошибок (`error` / `unhandledrejection`), чтобы нестабильные сетевые запросы к роутеру не ломали интерфейс Lampa.

## 🛠 Требования для работы механизма воспроизведения

Чтобы видео запускалось по клику на кнопку «Play», у вас должна быть настроена следующая связка:
1. **qBittorrent** установлен на роутере (или домашнем сервере) и к нему есть доступ по Web UI.
2. В qBittorrent настроен путь сохранения файлов (например, на внешний USB-диск, подключенный к Keenetic).
3. Этот же внешний диск (или папка с загрузками) расшарен в локальной сети по **SMB** с гостевым доступом или постоянным логином/паролем.
4. На вашем Android-устройстве (ТВ-приставке/телевизоре) установлен плеер, умеющий читать SMB-ссылки напрямую (например, **VLC** или **Vimu Media Player**).

## 📦 Установка в Lampa

1. Откройте **Lampa** ➡️ **Настройки** ➡️ **Расширения**.
2. Нажмите **Добавить плагин**.
3. Введите адрес https://a6u6ok.github.io/lampa-loadplaydel/preload.js.
3. Перезапустите Lampa.

## ⚙️ Настройка

При первом обращении к функциям плагина откроется **Мастер настройки**. Также вы можете изменить параметры в любой момент, перейдя в **Настройки** ➡️ **qBittorrent**.

### Основные параметры:
- **Адрес сервера:** URL вашего Web UI qBittorrent (например, `http://192.168.1.1:9080`).
- **Путь загрузки qBittorrent:** Абсолютный путь на самом роутере, куда qBittorrent физически качает файлы (пример: `/mnt/storage/torrents`).
- **Корень SMB-папки загрузок:** Сетевой путь до этой же папки в вашей локальной сети (пример: `smb://192.168.1.1/MEDIA/`).
- **Логин / Пароль:** Данные для авторизации в Web UI (если отключен обход аутентификации для локальной сети).

> 💡 **Как это работает:** Плагин берет путь готового файла из qBittorrent (например, `/mnt/storage/torrents/Movie.mkv`), отрезает локальный путь роутера (`/mnt/storage/torrents`) и подставляет ваш SMB-корень. На выходе получается ссылка `smb://192.168.1.1/MEDIA/Movie.mkv`, которая напрямую передается в видеоплеер.
